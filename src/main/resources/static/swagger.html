PassOn API

기본 주소 https://nextshift-1065882590623.asia-northeast3.run.app

가입과 로그인만 토큰 없이 호출합니다. 나머지 API는 헤더에 Authorization: Bearer 토큰을 넣습니다.

프론트 사용 방법

  1. 이 페이지는 주소창에 https://nextshift-1065882590623.asia-northeast3.run.app/swagger.html처럼 서버 주소로 엽니다. html 파일을 더블클릭하면 요청이 실패합니다.
  2. 먼저 아래 가입 또는 로그인의 실행을 누릅니다. 응답의 accessToken이 위 칸에 자동으로 들어갑니다. 토큰 앞에 Bearer를 적지 않습니다.
  3. 그 다음 API는 위 토큰으로 호출됩니다. 화면 코드에서는 헤더에 Authorization: Bearer 토큰을 넣습니다.
  4. 경로의 {storeId} 같은 칸에는 앞에서 받은 id를 그대로 붙여 넣습니다. 내 매장 id는 GET /api/stores 응답에 있습니다. 예시 글자를 그대로 보내면 실패합니다.
  5. 토큰은 15분 뒤 만료됩니다. 만료되면 POST /api/auth/refresh를 credentials: "include"로 호출해 새 토큰을 받습니다.
  6. API 주소를 브라우저 주소창에 붙여 넣으면 GET으로 열려서 401이 납니다. 화면에서는 fetch나 axios로 메서드를 지정해 호출합니다.
  7. 사진 올리기는 FormData에 필드 이름 file로 넣습니다. Content-Type은 코드에서 직접 넣지 않습니다. 사진 보기는 img의 src에 API 주소를 넣으면 토큰이 전달되지 않습니다. fetch로 받은 뒤 blob 주소로 보여 줍니다.
  8. 실패하면 응답의 message를 그대로 화면에 보여 주면 됩니다. 비밀번호는 8자 이상이고 영문 대문자, 소문자, 특수문자가 모두 있어야 합니다.
const base = "https://nextshift-1065882590623.asia-northeast3.run.app";

const login = await fetch(base + "/api/auth/login", {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ email, password })
});
const { accessToken } = await login.json();

const stores = await fetch(base + "/api/stores", {
  headers: { Authorization: "Bearer " + accessToken }
});

const form = new FormData();
form.append("file", fileInput.files[0]);
await fetch(base + "/api/users/me/photo", {
  method: "POST",
  headers: { Authorization: "Bearer " + accessToken },
  body: form
});

const photo = await fetch(base + "/api/users/me/photo", {
  headers: { Authorization: "Bearer " + accessToken }
});
img.src = URL.createObjectURL(await photo.blob());
